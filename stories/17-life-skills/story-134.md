# เรื่องที่ 134: First Aid (ปฐมพยาบาล)

## 📖 เรื่องสั้น (2 ภาษา)

### English Version (พร้อมคำอ่าน)

**First Aid**

Yod has a normal morning, but today feels different. Yod wants to learn something useful about first aid.
Yod แฮส อะ นอร์มอล มอร์นิง บัท ทูเดย์ ฟีลส์ ดิฟเฟอเรนท์ Yod วอนทส์ ทู เลิร์น ซัมธิง ยูสฟูล อะเบาท์ first aid

At first, the task looks simple. Then a small problem appears, and Yod has to think carefully.
แอท เฟิสท์ เดอะ ทาสค ลุคส์ ซิมเพิล เดน อะ สมอล พรอบเล็ม อะเพียร์ส แอนด์ Yod แฮส ทู ธิงค์ แคร์ฟูลลี

"I should not rush," Yod says. "I need a clear plan."
"ไอ ชูด นอท รัช" Yod เซย์ส "ไอ นีด อะ เคลียร์ แพลน"

Yod asks one question, checks the details, and tries again. The second try is much better.
Yod อาสค์ส วัน เควสชัน เช็คส์ เดอะ ดีเทลส์ แอนด์ ไทรส์ อะเกน เดอะ เซคันด์ ไทร อิส มัช เบทเทอร์

By the afternoon, Yod understands the lesson. Yod learns basic first aid.
บาย ดิ อาฟเทอร์นูน Yod อันเดอร์สแตนด์ส เดอะ เลสซัน Yod learns basic first aid

"Learning is easier when I stay calm and keep practicing," Yod says.
"เลิร์นนิง อิส อีซิเออร์ เวน ไอ สเตย์ คาล์ม แอนด์ คีพ แพรคทิซิง" Yod เซย์ส

---

### เวอร์ชันภาษาไทย

**ปฐมพยาบาล**

Yod มีเช้าที่ปกติ แต่วันนี้รู้สึกต่างออกไป Yod อยากเรียนรู้สิ่งที่เป็นประโยชน์เกี่ยวกับ first aid

ตอนแรก งานนี้ดูง่าย จากนั้นปัญหาเล็ก ๆ ก็เกิดขึ้น และ Yod ต้องคิดอย่างรอบคอบ

"ฉันไม่ควรรีบ" Yod กล่าว "ฉันต้องมีแผนที่ชัดเจน"

Yod ถามหนึ่งคำถาม ตรวจรายละเอียด และลองอีกครั้ง ครั้งที่สองดีขึ้นมาก

ตอนบ่าย Yod เข้าใจบทเรียน Yod learns basic first aid

"การเรียนรู้ง่ายขึ้นเมื่อฉันใจเย็นและฝึกต่อไป" Yod กล่าว

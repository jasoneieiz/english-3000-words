# เรื่องที่ 53: Learning to Code (เรียนเขียนโค้ด)

## 📖 เรื่องสั้น (2 ภาษา)

### English Version (พร้อมคำอ่าน)

**Learning to Code**

Nicha has a normal morning, but today feels different. Nicha wants to learn something useful about coding.
Nicha แฮส อะ นอร์มอล มอร์นิง บัท ทูเดย์ ฟีลส์ ดิฟเฟอเรนท์ Nicha วอนทส์ ทู เลิร์น ซัมธิง ยูสฟูล อะเบาท์ coding

At first, the task looks simple. Then a small problem appears, and Nicha has to think carefully.
แอท เฟิสท์ เดอะ ทาสค ลุคส์ ซิมเพิล เดน อะ สมอล พรอบเล็ม อะเพียร์ส แอนด์ Nicha แฮส ทู ธิงค์ แคร์ฟูลลี

"I should not rush," Nicha says. "I need a clear plan."
"ไอ ชูด นอท รัช" Nicha เซย์ส "ไอ นีด อะ เคลียร์ แพลน"

Nicha asks one question, checks the details, and tries again. The second try is much better.
Nicha อาสค์ส วัน เควสชัน เช็คส์ เดอะ ดีเทลส์ แอนด์ ไทรส์ อะเกน เดอะ เซคันด์ ไทร อิส มัช เบทเทอร์

By the afternoon, Nicha understands the lesson. Nicha builds a small website for her class.
บาย ดิ อาฟเทอร์นูน Nicha อันเดอร์สแตนด์ส เดอะ เลสซัน Nicha builds a small website for her class

"Learning is easier when I stay calm and keep practicing," Nicha says.
"เลิร์นนิง อิส อีซิเออร์ เวน ไอ สเตย์ คาล์ม แอนด์ คีพ แพรคทิซิง" Nicha เซย์ส

---

### เวอร์ชันภาษาไทย

**เรียนเขียนโค้ด**

Nicha มีเช้าที่ปกติ แต่วันนี้รู้สึกต่างออกไป Nicha อยากเรียนรู้สิ่งที่เป็นประโยชน์เกี่ยวกับ coding

ตอนแรก งานนี้ดูง่าย จากนั้นปัญหาเล็ก ๆ ก็เกิดขึ้น และ Nicha ต้องคิดอย่างรอบคอบ

"ฉันไม่ควรรีบ" Nicha กล่าว "ฉันต้องมีแผนที่ชัดเจน"

Nicha ถามหนึ่งคำถาม ตรวจรายละเอียด และลองอีกครั้ง ครั้งที่สองดีขึ้นมาก

ตอนบ่าย Nicha เข้าใจบทเรียน Nicha builds a small website for her class

"การเรียนรู้ง่ายขึ้นเมื่อฉันใจเย็นและฝึกต่อไป" Nicha กล่าว

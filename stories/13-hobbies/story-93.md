# เรื่องที่ 93: Running Club (ชมรมวิ่ง)

## 📖 เรื่องสั้น (2 ภาษา)

### English Version (พร้อมคำอ่าน)

**Running Club**

Aom has a normal morning, but today feels different. Aom wants to learn something useful about running.
Aom แฮส อะ นอร์มอล มอร์นิง บัท ทูเดย์ ฟีลส์ ดิฟเฟอเรนท์ Aom วอนทส์ ทู เลิร์น ซัมธิง ยูสฟูล อะเบาท์ running

At first, the task looks simple. Then a small problem appears, and Aom has to think carefully.
แอท เฟิสท์ เดอะ ทาสค ลุคส์ ซิมเพิล เดน อะ สมอล พรอบเล็ม อะเพียร์ส แอนด์ Aom แฮส ทู ธิงค์ แคร์ฟูลลี

"I should not rush," Aom says. "I need a clear plan."
"ไอ ชูด นอท รัช" Aom เซย์ส "ไอ นีด อะ เคลียร์ แพลน"

Aom asks one question, checks the details, and tries again. The second try is much better.
Aom อาสค์ส วัน เควสชัน เช็คส์ เดอะ ดีเทลส์ แอนด์ ไทรส์ อะเกน เดอะ เซคันด์ ไทร อิส มัช เบทเทอร์

By the afternoon, Aom understands the lesson. Aom joins a running club.
บาย ดิ อาฟเทอร์นูน Aom อันเดอร์สแตนด์ส เดอะ เลสซัน Aom joins a running club

"Learning is easier when I stay calm and keep practicing," Aom says.
"เลิร์นนิง อิส อีซิเออร์ เวน ไอ สเตย์ คาล์ม แอนด์ คีพ แพรคทิซิง" Aom เซย์ส

---

### เวอร์ชันภาษาไทย

**ชมรมวิ่ง**

Aom มีเช้าที่ปกติ แต่วันนี้รู้สึกต่างออกไป Aom อยากเรียนรู้สิ่งที่เป็นประโยชน์เกี่ยวกับ running

ตอนแรก งานนี้ดูง่าย จากนั้นปัญหาเล็ก ๆ ก็เกิดขึ้น และ Aom ต้องคิดอย่างรอบคอบ

"ฉันไม่ควรรีบ" Aom กล่าว "ฉันต้องมีแผนที่ชัดเจน"

Aom ถามหนึ่งคำถาม ตรวจรายละเอียด และลองอีกครั้ง ครั้งที่สองดีขึ้นมาก

ตอนบ่าย Aom เข้าใจบทเรียน Aom joins a running club

"การเรียนรู้ง่ายขึ้นเมื่อฉันใจเย็นและฝึกต่อไป" Aom กล่าว

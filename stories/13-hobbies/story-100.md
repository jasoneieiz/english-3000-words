# เรื่องที่ 100: Writing a Journal (เขียนบันทึก)

## 📖 เรื่องสั้น (2 ภาษา)

### English Version (พร้อมคำอ่าน)

**Writing a Journal**

Pin has a normal morning, but today feels different. Pin wants to learn something useful about journal.
Pin แฮส อะ นอร์มอล มอร์นิง บัท ทูเดย์ ฟีลส์ ดิฟเฟอเรนท์ Pin วอนทส์ ทู เลิร์น ซัมธิง ยูสฟูล อะเบาท์ journal

At first, the task looks simple. Then a small problem appears, and Pin has to think carefully.
แอท เฟิสท์ เดอะ ทาสค ลุคส์ ซิมเพิล เดน อะ สมอล พรอบเล็ม อะเพียร์ส แอนด์ Pin แฮส ทู ธิงค์ แคร์ฟูลลี

"I should not rush," Pin says. "I need a clear plan."
"ไอ ชูด นอท รัช" Pin เซย์ส "ไอ นีด อะ เคลียร์ แพลน"

Pin asks one question, checks the details, and tries again. The second try is much better.
Pin อาสค์ส วัน เควสชัน เช็คส์ เดอะ ดีเทลส์ แอนด์ ไทรส์ อะเกน เดอะ เซคันด์ ไทร อิส มัช เบทเทอร์

By the afternoon, Pin understands the lesson. Pin writes about each day.
บาย ดิ อาฟเทอร์นูน Pin อันเดอร์สแตนด์ส เดอะ เลสซัน Pin writes about each day

"Learning is easier when I stay calm and keep practicing," Pin says.
"เลิร์นนิง อิส อีซิเออร์ เวน ไอ สเตย์ คาล์ม แอนด์ คีพ แพรคทิซิง" Pin เซย์ส

---

### เวอร์ชันภาษาไทย

**เขียนบันทึก**

Pin มีเช้าที่ปกติ แต่วันนี้รู้สึกต่างออกไป Pin อยากเรียนรู้สิ่งที่เป็นประโยชน์เกี่ยวกับ journal

ตอนแรก งานนี้ดูง่าย จากนั้นปัญหาเล็ก ๆ ก็เกิดขึ้น และ Pin ต้องคิดอย่างรอบคอบ

"ฉันไม่ควรรีบ" Pin กล่าว "ฉันต้องมีแผนที่ชัดเจน"

Pin ถามหนึ่งคำถาม ตรวจรายละเอียด และลองอีกครั้ง ครั้งที่สองดีขึ้นมาก

ตอนบ่าย Pin เข้าใจบทเรียน Pin writes about each day

"การเรียนรู้ง่ายขึ้นเมื่อฉันใจเย็นและฝึกต่อไป" Pin กล่าว

## 📚 คำศัพท์สำคัญ (Vocabulary)

| Word | คำอ่าน | ความหมาย | ตัวอย่าง |
|------|--------|----------|----------|
| useful | ยูสฟูล | เป็นประโยชน์ | This lesson is useful. |
| task | ทาสค | งานที่ต้องทำ | The task looks simple. |
| problem | พรอบเล็ม | ปัญหา | A small problem appears. |
| carefully | แคร์ฟูลลี | อย่างรอบคอบ | Think carefully. |
| rush | รัช | รีบ | Do not rush. |
| plan | แพลน | แผน | I need a clear plan. |
| detail | ดีเทล | รายละเอียด | Check the details. |
| practice | แพรคทิส | ฝึกฝน | Keep practicing. |
| calm | คาล์ม | ใจเย็น | Stay calm. |
| lesson | เลสซัน | บทเรียน | Pin understands the lesson. |

# เรื่องที่ 75: Clean Beach (ชายหาดสะอาด)

## 📖 เรื่องสั้น (2 ภาษา)

### English Version (พร้อมคำอ่าน)

**Clean Beach**

Nan has a normal morning, but today feels different. Nan wants to learn something useful about beach.
Nan แฮส อะ นอร์มอล มอร์นิง บัท ทูเดย์ ฟีลส์ ดิฟเฟอเรนท์ Nan วอนทส์ ทู เลิร์น ซัมธิง ยูสฟูล อะเบาท์ beach

At first, the task looks simple. Then a small problem appears, and Nan has to think carefully.
แอท เฟิสท์ เดอะ ทาสค ลุคส์ ซิมเพิล เดน อะ สมอล พรอบเล็ม อะเพียร์ส แอนด์ Nan แฮส ทู ธิงค์ แคร์ฟูลลี

"I should not rush," Nan says. "I need a clear plan."
"ไอ ชูด นอท รัช" Nan เซย์ส "ไอ นีด อะ เคลียร์ แพลน"

Nan asks one question, checks the details, and tries again. The second try is much better.
Nan อาสค์ส วัน เควสชัน เช็คส์ เดอะ ดีเทลส์ แอนด์ ไทรส์ อะเกน เดอะ เซคันด์ ไทร อิส มัช เบทเทอร์

By the afternoon, Nan understands the lesson. Nan joins a beach cleanup.
บาย ดิ อาฟเทอร์นูน Nan อันเดอร์สแตนด์ส เดอะ เลสซัน Nan joins a beach cleanup

"Learning is easier when I stay calm and keep practicing," Nan says.
"เลิร์นนิง อิส อีซิเออร์ เวน ไอ สเตย์ คาล์ม แอนด์ คีพ แพรคทิซิง" Nan เซย์ส

---

### เวอร์ชันภาษาไทย

**ชายหาดสะอาด**

Nan มีเช้าที่ปกติ แต่วันนี้รู้สึกต่างออกไป Nan อยากเรียนรู้สิ่งที่เป็นประโยชน์เกี่ยวกับ beach

ตอนแรก งานนี้ดูง่าย จากนั้นปัญหาเล็ก ๆ ก็เกิดขึ้น และ Nan ต้องคิดอย่างรอบคอบ

"ฉันไม่ควรรีบ" Nan กล่าว "ฉันต้องมีแผนที่ชัดเจน"

Nan ถามหนึ่งคำถาม ตรวจรายละเอียด และลองอีกครั้ง ครั้งที่สองดีขึ้นมาก

ตอนบ่าย Nan เข้าใจบทเรียน Nan joins a beach cleanup

"การเรียนรู้ง่ายขึ้นเมื่อฉันใจเย็นและฝึกต่อไป" Nan กล่าว
